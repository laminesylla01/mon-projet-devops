# mon-projet-devops

Projet d'apprentissage DevOps : une petite application web déployée automatiquement.

Outils : GitHub, Docker, Terraform, Ansible, Jenkins (sur Proxmox, conteneurs LXC).

## Structure
- `app/` : l'application Flask
- `terraform/` : création des CT (à venir)
- `ansible/` : configuration des CT (à venir)
- `Jenkinsfile` : pipeline CI/CD (à venir)
